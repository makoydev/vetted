# Controls matrix (v0, Milestone 1)

Each row maps something Vetted does to the principle, obligation or control it supports, with the source and section. It then says where the evidence is, so a reviewer can check the claim rather than take it on trust.

**Grades.** **P** = primary source (the issuing body's own publication), read for this matrix on 2026-09-30. **S** = secondary source. Anything not verified is marked as such. **"By analogy"** means the source doesn't strictly cover Vetted, and the row explains why it's still relevant.
